1它是做什么的

MSBOOST 启动器把“节点客户端”和“按程序分流”合进了一个小窗口。开始加速后，它只把 MapleStory 相关程序的连接送进你的 MSBOOST 节点，其他软件一律不碰。

MapleStory登录器 · 反作弊
MSBOOST 加速
你的节点你自己的 VPS
游戏服务器看到的是节点 IP
其他软件浏览器 · 聊天 · 下载
直连，不经过节点
互联网和平时一样

开始加速后：游戏走节点，其他软件照常直连

只加速游戏

按程序分流：MapleStory、Nexon 登录器、反作弊等程序走节点，其他软件不受影响。

不乱改系统

不改路由表、DNS 和系统代理，也不装虚拟网卡。停止加速就恢复原样。

解压即用

不用安装。节点配置、日志和设置都保存在程序所在的文件夹里。

开始前需要准备

  • 64 位 Windows 10 或 Windows 11（不支持 32 位系统和 ARM 版 Windows）。
  • 一份 MSBOOST 节点配置文件（.json）：在 MSBOOST 网站「部署 MSBOOST」完成后下载；不想在网站填写 SSH 的话，也可以用 MSBOOST 本地版在自己电脑上部署生成。

杀毒软件报毒？

启动器带有网络分流驱动，并且需要管理员权限，部分杀毒软件可能误报。可以把程序文件夹加入白名单，或者向杀毒软件厂商提交误报。

3导入节点配置

节点配置是一个 .json 文件，里面有节点的地址和连接密码，启动器靠它连接你的节点。它可能来自：

MSBOOST 网站

「部署 MSBOOST」完成后点「下载配置」；以后也能在同一个浏览器的「任务记录」里再次下载。

MSBOOST 本地版

和启动器放在同一个文件夹时，部署出的配置会直接存进启动器的 configs 文件夹，不用再导入。

中转配置

建好中转后得到的新配置（例如「日本中转.json」），导入方法完全一样。

两种导入方法，任选一种

方法 A：导入配置文件

打开 节点配置 页，点 导入配置文件…，选中下载的 .json 文件。

方法 B：放进 configs 文件夹

点 打开配置文件夹，把 .json 文件复制进去，再点 刷新。

  1. 1导入配置文件…：选一个 .json 导入
  2. 2打开配置文件夹（程序旁边的 configs）
  3. 3刷新：手动放进文件后点一下
  4. 4「当前」：开始加速时用的就是这份
  5. 5设为当前：改用这份配置
  6. 6无效的配置会标红并写明原因，可以删掉

列表里显示的名字就是文件名（不含 .json），下面一行是它的入口地址。导入时如果 configs 里已经有同名但内容不同的文件，程序会先问你是否替换。加速中不能切换配置，也不能删除正在用的配置，请先停止加速。

保管好配置文件

配置文件里有节点的连接密码，请自己备份好，不要发给别人。节点重新部署后会生成新配置，旧配置随之失效，记得换上新的。

4开始加速

  1. 选好节点配置

    回到 加速 页，在“节点配置”下拉框里选要用的配置。

  2. 按需打开可选加速

    Discord、Steam 默认关闭，需要时再打开，见第 6 节。

  3. 点「开始加速」

    几秒后状态变成绿色的 ● 加速中，托盘图标也变成橙色。

  4. 再打开 MapleStory

    用 Nexon 登录器或 Steam 照常启动游戏就行。

  1. 1选择节点配置（右边「管理」跳到节点配置页）
  2. 2可选加速：Discord、Steam 开关
  3. 3网络检测：开始检测；「详情」看完整结果
  4. 4开始加速
  1. 1状态：加速中（下一行是补充说明）
  2. 2网络检测概要：MSBOOST IPv4、到中转和到游戏的延迟
  3. 3停止加速
  4. 4状态栏：已运行时间、已使用流量、实时速率；右边是当前配置
先加速，再开游戏

已经建立的连接不会改走节点。如果游戏（包括登录器）已经开着，先把它关掉，开始加速后再重新打开。

开着 v2rayN、Clash 等代理软件？

它们的“系统代理”开着时，「加速」页会像上图一样显示 “已接管系统代理 127.0.0.1:10808：游戏发往它的请求改由 MSBOOST 发出”（地址以你的代理软件为准）。这是正常的：游戏的请求改由 MSBOOST 节点发出，其他软件仍照常用它们的代理；加速中开关代理软件，几秒内会自动跟上。

代理软件的 TUN 模式（虚拟网卡）建议在加速时关掉，否则游戏流量可能被代理两次。

停止加速

点 停止加速 即可。如果 MapleStory 还开着，程序会先提醒你：停止加速会断开游戏连接。

5网络检测

检测能告诉你：游戏服务器看到的是哪个 IP，线路每一段的延迟是多少。加速前后都能检测：在 网络检测 页点 开始检测，或者在「加速」页点 重新检测。两项延迟各测 3 次取平均。

  1. 1当前到游戏服务器 IPv4：游戏服务器看到的 IP，应该是你节点（VPS）的 IP。
  2. 2当前到中转服务器延迟：这台电脑到配置入口的延迟。直连配置的入口就是节点本身；中转配置的入口是中转服务器。
  3. 3当前到游戏服务器延迟：从这台电脑出发，经过节点连上“游戏测速目标”的全程延迟，最接近游戏里的实际延迟。
  4. 4重新检测

延迟高，或者测不出来？

到中转这段高

这台电脑到入口的线路不好。换一台线路更好的中转服务器，或者换个时间段再测。

到游戏整体高

多半是节点 VPS 离游戏服务器太远，换一台离游戏服务器更近的 VPS。

到游戏测不出来

先确认“游戏测速目标”是你玩的服务器（第 6 节）。仍然超时的话，可能是节点到游戏服务器的网络有问题。

小枫说

“当前到游戏服务器 IPv4”不是你的节点 IP？先看「加速」页是不是选对了配置。用朋友的中转时，这里也应该是你自己节点的 IP：中转不会改变游戏出口。

  1. 1Discord：语音使用 UDP，一并加速
  2. 2Steam：Steam 下载也会经过节点，会消耗节点流量

两个开关默认关闭，「加速」页上也有同样的开关。加速中切换只对新连接生效。

Steam 版 MapleStory 不用开「Steam」

从 Steam 启动的 MapleStory 和它的登录窗口本来就在加速对象里：先开始加速，再照常从 Steam 启动游戏就行。只有想让 Steam 客户端本身（商店、下载）也走节点时才需要打开这个开关。

7日志与诊断包

  1. 1按来源筛选：全部 / 程序 / 核心 / 分流
  2. 2打开日志文件夹（程序旁边的 logs）
  3. 3导出诊断包：生成一个 .zip，反馈问题时附上

日志按天保存 7 天。往上翻看旧日志时不会自动滚到底，点 回到最新 ↓ 就能回到最新一行。

诊断包只发给客服

日志和诊断包里有你的节点地址。遇到问题时，在 MSBOOST 网站提交工单并附上诊断包；不要发到群里或公开论坛。

9常见问题

提示“检测到 ProxyBridge 正在运行”，不能开始加速

ProxyBridge 会和 MSBOOST 抢用同一个分流驱动。点提示条上的 停止 ProxyBridge ①：程序会让 ProxyBridge 退出（和它托盘菜单里的“退出”一样），并停止它的后台服务。

如果 ProxyBridge 设置了开机启动，下次开机它还会运行；不再使用的话，建议卸载它。

提示“检测到 Netch 正在运行”

这是黄色提醒，不影响开始加速。但 Netch 和 MSBOOST 同时加速游戏可能会重复代理，建议先退出 Netch。

提示“分流所需的本地端口被占用”

有别的程序占用了分流要用的本地端口。关掉提示里说的占用程序后重试；不确定是哪个程序的话，重启电脑再试。

提示“另一个 MSBOOST 程序正在使用加速核心”

同一时间只能有一个 MSBOOST 程序加速。关掉另一个 MSBOOST 程序（例如命令行工具 msboostctl）后，重新打开启动器。

双击程序后没看到窗口

启动器可能已经在托盘里运行了：单击托盘里的枫叶图标，或者再双击一次 exe，已经打开的窗口会被调出来。如果在“用户账户控制”里点了“否”，程序不会打开，重新双击并点“是”即可。

网络检测提示“节点未提供兼容的版本 2 全程 TCP 测速服务”

节点的安装版本比较旧，还没有全程测速服务；不影响加速本身。可以用 MSBOOST 本地版的「升级节点」（保留原配置），或者在网站重新部署（会生成新配置，旧配置失效）。

MapleStory 登录器提示“所在地区不支持”，或者登录窗口一直转圈
  • 确认是先开始加速、再打开登录器的；如果顺序反了，关掉登录器重新打开。
  • 开着 v2rayN、Clash 的系统代理也没关系，启动器会接管游戏的请求（见第 4 节）；TUN 模式请先关掉。
  • 用网络检测看看“当前到游戏服务器 IPv4”是不是你的节点 IP。
  • 还不行的话，在「日志」页导出诊断包，提交工单时附上。
加速后延迟还是高

看网络检测：到中转这段高，换一台线路更好的中转服务器；到游戏整体高，多半是节点 VPS 离游戏服务器太远。

Steam 版 MapleStory 可以用吗？

可以。先在启动器里开始加速，再照常从 Steam 启动 MapleStory，登录窗口和游戏都会走加速。不需要打开「Steam」可选加速。

要一直开着启动器吗？

玩游戏时要保持加速。关掉窗口只是缩到托盘，不影响加速；从托盘菜单“退出”或在设置页“退出程序”才会停止加速。

10更新、换电脑与卸载

更新到新版本

启动器不会自动更新。在 MSBOOST 网站下载新版本，先从托盘菜单“退出”旧版，再把新 zip 里的文件解压到原来的文件夹、覆盖同名文件。configs 里的节点配置和设置都会保留。

换电脑

退出程序后，把整个文件夹复制到新电脑就行：节点配置、日志和设置都在里面。

卸载

先在「设置与关于」页点「清理」，再退出程序，最后删除整个程序文件夹。清理报告里如果有文件“已安排在下次重启电脑时删除”，重启后就会删掉。

全部学会啦！

还有问题的话，在「日志」页导出诊断包，到 MSBOOST 网站提交工单，客服会尽快回复。
