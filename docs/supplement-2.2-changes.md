# 《补充说明 2.2》整改说明

此文档对应用户在安装 v0.2.2 后提交的补充说明，计划随 v0.2.3 发布。不代表已自动更新 msboost.de，也不代表旧 v0.2.2 标签包含这些新功能。

## 首页与文章

登录页标题固定两行：首行“一键部署你的”为深色，第二行“独立IP游戏节点”全行为橙色。窄屏仍保留两行，不把“节点”挤到第三行。

文章增加“资讯”分类。新文章默认插入普通文章组的最前面；置顶文章单独排在所有普通文章之前，旧置顶文章不会被新的普通文章挤下去。每组内可上移、下移、最顶、最底。旧记录中的 `sort` 可能含管理员人工排序，升级保留它，不擅自重排历史文章。相同排序值有稳定的时间、ID 排序兜底。

新建文章即显示附件区。首次上传会先自动保存未发布草稿，再沿用现有附件上传接口；不会自动发布。关闭编辑器后草稿仍保留，上传失败可回到原草稿重试。文章需要显式发布，草稿附件仍受管理权限保护。

## 易支付的地址和兼容范围

这些名称通常不是五个独立接口：

| 名称 | 本项目用途 |
| --- | --- |
| 通知地址 / 异步回调地址 `notify_url` | 支付平台通知 MSBOOST；验签、核对商户/渠道/订单/金额/币种与成功状态，再事务入账。 |
| 同步地址 / 返回地址 / 支付返回入口 `return_url` | 付款后让浏览器回到本站，显示当前用户订单的服务端状态；回跳本身不入账。 |

MSBOOST 用唯一的站点 `PUBLIC_URL` 自动生成地址，在每次下单时一起签名提交。通知地址为 `https://你的域名/api/payments/epay/渠道ID/notify`，返回地址为 `https://你的域名/?order=订单ID`。后台现在显示只读地址及复制入口，通常不需要再手填；供应商若有商户域名或回调白名单，仍需在供应商后台单独配置。

区别是 Dujiao 允许手填这两个地址，MSBOOST 自动从本站地址推导，不需要为了有相同的表单而接受任意回调地址。[Dujiao 支付指南](https://dujiao-next.com/payment/guide)、[易支付 V1 文档](https://yzf.yzfpay.com/doc/v1_legacy_api.html)。

现有收银台跳转支持 V1 `/submit.php` 的 MD5 和 V2 `/api/pay/submit` 的 RSA-SHA256。不同供应商可能有自己的协议变体，不能把同名“易支付”视为全部兼容。[易支付签名说明](https://yzf.yzfpay.com/doc/sign_note.html)。

本次补齐浏览器回跳后的登录续接、本人订单定位、有限次数轮询和手动刷新。未付款、已过期、待人工复核与已支付分别显示；不相信 URL 中的“成功”字段，不能查询他人的订单。后台异步重复通知不会重复发放权益。

真实商户下单、实际扣款与收款、主动向供应商查单、退款及财务对账不由这些自动测试代替。网页轮询查的是本站订单，不是支付平台补偿查单。生产启用前仍需使用自己的商户配置完成小额真实支付和回调验收。

## 两层备份

网页备份和部署整站备份是两种不同用途，不能互换：

| 项目 | 网页业务备份 | 安装脚本整站灾难备份 |
| --- | --- | --- |
| 内容 | 加密业务状态，包括文章附件 | 业务快照、PostgreSQL 自定义导出、原 `.env`/主密钥、部署配置、应用目录和证书卷 |
| 默认本机位置 | Docker 应用数据卷中的备份目录 | `/root/msboost-backup`，独立于 `/opt/msboost` |
| 远程登录 | 专用私钥或密码；后台密文保存、API 不回传 | SSH 密码；root-only 本机配置文件，密码不在命令行或日志中 |
| 计划 | 网页设置的业务备份计划 | 此 VPS 的独立 systemd 每日计划；需要明确启用 |
| 恢复 | 保留当前财务状态的网页安全恢复 | 全新目标整站恢复，使用备份时间点的财务数据；不覆盖现有站点 |

两种远程方式都要求公网 IP、端口、用户名和独立核对过的 SHA256 主机指纹。默认 root、`/root/msboost-backup`；支持创建私有目标目录，拒绝符号链接和不安全目录，文件写入前设为 0600，并回读校验 SHA256。目标目录须由登录用户所有，上级目录须由 root 或该用户所有且不可被其他用户写入；非 root 用户应使用自己的专用目录。

网页备份目标更新时，密码留空仅在原认证模式下保留已有凭据，切换模式必须提供新凭据。整站备份配置向导则每次重设计划，选择远端时必须重新输入密码，不沿用留空密码；远程 IP 留空会改为仅本机备份。

整站包包含可解密本站所有业务秘密的原主密钥和数据库密码。即使其中 `state.msb` 已加密，**整个整站包仍是敏感明文归档，不可放到公开下载目录、GitHub、工单或聊天中**。HTTPS Release 校验仅验证工具来源；包内摘要仅检测损坏，不证明陌生人发来的备份可信。

操作入口、恢复限制及中断处理参见[整站灾难备份操作](disaster-backup.md)。
