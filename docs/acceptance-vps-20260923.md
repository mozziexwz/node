# v0.3.2 临时 VPS 验收记录

日期：2026-09-23。以下 7 台 VPS 均由用户明确授权重装和清理；本记录不包含 SSH 密码、站点密钥、注册令牌或客户配置内容。控制面通过 Cloudflare 代理的 `msboost.de` 对外提供 HTTPS。下表实测使用与 v0.3.2 功能代码相同的 v0.3.1-dev.2 候选构建；v0.3.1 标签因安装器测试固定旧版本号而未发布制品，v0.3.2 修复了该测试并重新接受 CI 检查。

## 发布与验收边界

本轮将控制面支持范围限定 Debian 12/13，免费客户部署工具与 Agent 支持 Debian 11/12/13。Debian 11 已结束官方 LTS，只作为兼容目标，不推荐公开生产使用。站点诊断只是入口和目标分别进行的 TCP 初检；真实 HTTP 转发验收另列于上，不等同于游戏协议或 Mieru 认证验收。

上述真实中转覆盖单节点与双节点端口转发；已有连接的 30 分钟 `keep_last` 耐久性另由独立 CI 的真实 GOST 用例验收，不能用“Agent 在线”替代。真实游戏登录、商户扣款、外部 SMTP 投递、arm64 真机、极限并发/流量计费和公网 WAF 攻防测试未在这 7 台 VPS 上完成，不能据此宣称全部业务达到无条件生产 SLA。SMTP 功能由用户另行测试，本轮未重复发送邮件。

本轮真实会员、线路和规则为测试数据，正式安装前应清理；此页不公布可复用的测试凭据或注册令牌。发布标签、双架构预构建镜像和 Release 资产只有在对应 CI 与清单验证通过后才算正式可安装。
