# 会员找回密码与本机管理员改密

本功能的产品规则来自 2026-09-15 补充确认：普通会员允许未验证邮箱找回；管理员禁止邮件找回，通过控制面服务器本机安装器修改密码。

## 会员自助找回

- 登录页选择“忘记密码”，输入注册时使用的纯数字 QQ 邮箱，获取六位验证码后填写两次新密码。
- 正常会员无论 `EmailVerifiedAt` 是否为空均可恢复；停用账号、管理员及未知角色不能恢复。前后端均不靠用户提交的角色判断权限。
- SMTP 必须已经配置并通过后台测试；与是否开放注册、是否要求注册邮箱验证相互独立。
- 密码至少 8 个字符且不超过 72 个 UTF-8 字节，不得等于完整邮箱或邮箱前缀，也不得包含连续 6 位或以上 ASCII 数字。页面只显示简明的“密码至少8字符。”；注册、会员找回和管理员本机改密使用同一服务端策略。改密不会更改邮箱验证状态、角色、枫叶、流量或权益。
- 成功后撤销该会员的全部旧会话、消费验证码并清除待完成的找回挑战；不自动登录。密码重置成功通知不包含密码。
- 管理员不能利用此入口重置密码，即使人为构造了验证码，或在发送过程中由会员提升为管理员，也会被后端拒绝。

### 接口

`POST /api/auth/password/reset/request` 接受 `email`、`turnstileToken`。

对有效格式的会员、管理员、不存在的邮箱以及冷却中请求，正常响应使用相同提示、`retryAfter: 60`、`expiresIn: 600`；不透露账号资格。邮件服务整体不可用、请求限流或工作槽满时返回通用错误。

`POST /api/auth/password/reset/confirm` 接受 `email`、`code`、`newPassword`、`turnstileToken`。仍须通过启用的人机验证与来源检查。验证码不存在、过期、超出错误次数、用途错误、账号不符合资格等均为同一业务拒绝提示。

### 防护与投递边界

- 10 分钟有效、60 秒重发冷却、最多 5 次错误；验证码仅保存随机挑战 ID 与校验哈希，并绑定发起时的密码凭据版本。成功只能消费一次。
- 密码哈希计算在写事务之外完成；最终事务重新检查资格、邮箱、Owner、凭据版本与挑战，原子完成消费、改密、会话撤销和审计。
- 申请每 IP 20 次/小时、每邮箱 5 次/小时；确认每 IP 30 次/15 分钟、每邮箱 15 次/15 分钟；各接口另有每进程 100 次/分钟的容量限制。邮箱限流键为摘要，不记录原始邮箱。
- 应用层限流为当前单实例的内存限流，不能称为分布式全局限流。已创建挑战的 60 秒冷却和错误次数另受数据库事务保护。
- 发信为最多 8 个并行工作槽的短期任务，不持久化明文验证码，不因等待 SMTP 的不同耗时暴露邮箱是否存在。它不是可靠消息队列：进程意外退出可能丢失尚未完成投递，用户需在冷却后重试。
- 发送失败只清理同一挑战 ID，不能擦除更新的并发请求。SMTP 已接受 DATA 后，QUIT 失败不再视为未发送。
- 重置成功通知的投递失败不会回滚已成功修改的密码；失败记录仅含脱敏收件人和错误类别，不含正文、验证码、密码或原始 SMTP 错误。
- 前端倒计时只改善交互，服务器仍是最终限流与验证码有效性依据；切换认证模式或编辑邮箱不能清空当前页面的保守冷却。

采用五类内嵌模板：注册验证码、已登录邮箱验证、找回密码验证码、重置成功通知、SMTP 测试。统一中文主题、HTML/纯文本双版本，品牌字样全黑；官网链接仅来自可信 HTTPS `PublicURL`。HTML 美化与 SMTP 接受均不保证进入收件箱，部署者仍应以实际收件邮箱验证渲染和投递。

## 管理员本机改密

安装器发布文件名为 `msboost-install.sh`，仓库源文件为 `install.sh`。包含本功能的版本安装/升级后，可使用：

```bash
msboost admin-password
# 或
bash msboost-install.sh admin-password
```

也可在安装器菜单选择“12) 修改已有管理员密码”。命令仅允许目标 Debian 12 服务器的 root 在本机交互终端执行，禁止通过命令参数或环境变量传入新密码。输入已有管理员邮箱、两次新密码，并确认目标后才提交。

它使用已安装且固定身份的官方镜像，通过标准输入向本机数据库事务提交改密。不会创建管理员、提升会员权限、停止面板或重启中转，不改维护状态及其他业务数据。管理员旧会话与未完成恢复挑战会失效。`.env` 中的 `ADMIN_PASSWORD` 是初始化值，不会在重启时覆盖已存在管理员的新密码。

本机改密需要数据库容器正常运行和可写；数据库离线时不自动启动、修复或恢复数据。它也不能替代账号停用状态的处理。

**版本边界：** 仅下载新版入口脚本不会给旧镜像增加功能，必须先安装/升级到包含 `admin-password` 子命令的版本。此文档不代表变更已经发布到 GitHub 或生产服务器。

## 回归与未覆盖范围

新增恢复测试覆盖已验证/未验证、管理员/停用、用途隔离、过期、五次错误、并发单次消费、旧密码版本、发送期间角色变化、通知失败、取消发送和关机等待。安装器测试覆盖 root/TTY、双次输入、目标范围与秘密传递；生产数据库方言由可选 PostgreSQL 集成测试覆盖。

本次不改中转租约/离线保留、不修改线上密码、不调整支付数据，不代表附件 2.3 的全部其他整改已经完成。
