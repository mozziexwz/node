# MSBOOST 首个 VPS 调试版本

v0.1.1 修复首次云端容器验收发现的动态 IP 与 Caddy 固定地址冲突，以及 GitHub 单行 JSON 的升级版本解析问题。v0.1.0 未通过完整发布检查，没有生成可安装的正式 Release；请使用 v0.1.1。

面向 Debian 12（amd64 / arm64）。网站默认使用 Docker Compose 拉取 GHCR 预构建镜像；发布包与独立执行机/节点二进制提供 SHA-256 校验。

- 一键安装、升级、修复、状态和日志；卸载默认保留数据库与密钥；彻底清理是独立双重确认操作。
- 按补充说明完善用户单位与排序、卡密记录、套餐限购、邮箱购买门槛、节点与隧道、文章和工单。
- 后台提供执行机与节点注册令牌及一键安装入口。

先在测试 VPS 验收。重装系统、客户 SSH 执行和网络配置具有实际破坏性，不会由本站安装脚本自动执行。完整在线任务需要 HTTPS 域名及已注册执行机；IP HTTP 模式仅用于界面调试，不能代替生产 HTTPS。

优先拉取 GHCR 镜像；若镜像包尚未公开或仓库访问失败，自动改为下载同版本 Release 中经过 SHA-256 校验的预构建镜像归档并导入 Docker。两种来源均失败则停止，不会静默切换本机构建。参考仓库 README 和 docs/deployment.md。
