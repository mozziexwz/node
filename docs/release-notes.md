# 发布说明

## v2.2.2 · 系统设置读取保护

- 系统设置必须读取成功并填入表单后才允许编辑，防止网络慢时将尚未加载的开关误保存为关闭。
- 保存后的重新读取若失败，停止编辑并提供重试入口，不再使用旧值或空值继续保存。
- 增加慢请求、首次读取失败、保存后刷新失败及重试成功的浏览器回归测试。

包含 v2.2.1 的全部修复。本次新增修复只涉及面板设置页；已升级至 v2.2.1 的执行机和中转节点无需为此补丁重复升级。仍使用旧版的节点应按 v2.2.1 说明原地升级，保留身份和配置。

## v2.2.1 · 任务、备份与节点防火墙维护

- 包含下方 v2.2.0 的任务补报、备份恢复、界面及脚本改进。
- 修复 UFW 自动放行规则的顺序：改用用户规则之后的独立入口，管理员后来新增的拒绝规则也立即优先，不等待维护轮询。
- 原地升级保留节点身份和转发配置；只清理本项目带归属标记的旧入口，不删除管理员规则、其他服务规则或节点数据。
- 增加真实 UFW 的新增拒绝、撤销拒绝、反复重载及 systemd 权限隔离回归验证。

面板、执行机和中转节点需分别升级。节点升级会短暂中断连接，请安排维护时间；无需卸载或全新重装。自动维护仅针对 UFW，云防火墙和其他防火墙仍需由管理员放行。在线支付及邮箱服务不包含在本轮验收中。

## v2.2.0 · 预发布（请使用 v2.2.1）

本版本发现自动放行入口可能优先于后来新增的 UFW 拒绝规则，已撤出推荐稳定发布；使用 v2.2.1 修复该问题。

- 修复启用 UFW 时权益端口未放行的问题：独立维护组件按实际监听端口管理本项目规则，保留其他应用与管理员规则；增加防火墙待处理状态，不将本地监听冒充公网连通。
- 面板重启后保留执行中服务器占用；支持原结果补报和明确的任务核对入口，不重复执行部署或重装。
- 执行机结果支持最长 30 分钟退避重试和重复确认；忙时停用先停止接新任务，已有结果可继续回传。
- 统一可恢复备份容量预算，超限附件在保存前拒绝；业务备份增加容量提示与异地目标连接、写入和回读测试。
- 修复异地业务备份在 SSH 服务器提供多种主机密钥时误拒绝已核对指纹的问题；仅在匹配指纹后进行密码或私钥认证。
- 镜像增加可覆盖的 Go 内存软目标，降低连续大附件备份时的垃圾内存峰值；容量预算不再被误解为内存需求保证。
- 同一整站备份中断恢复可续跑；保护其他网站和人工修改的配置，重复导入使用新的隔离数据库。
- 增加执行机单独卸载及残缺节点安装清理，先扫描、明确确认、保存私有备份；显示 Agent 程序版本和真实管理同步。
- 修复任务记录忽略本机自动保存开关、本机改密规则不一致，以及恢复和权益说明过时的问题。
- 节点、执行机、隧道、任务和备份页区分读取中、读取失败与真实空记录；小备份使用 KiB 显示，不再误报为 0.00 MB。
- 业务备份计划必须完整读取计划和远程目标后才能编辑；读取失败可重试，防止将尚未加载的已选异地目标意外取消。

网站和独立执行机需分别升级，才能使用完整的结果补报能力；升级 Agent 会中断其正在执行的工作或节点连接，请在空闲时进行。在线支付及邮箱服务不包含在本轮功能验收中。
## v2.1.1 · 节点本机卸载修复

- 修复卸载脚本漏识别新版健康及注册状态文件，误报“身份或转发终态不匹配”的问题。
- 本机 root 明确确认后，可离线卸载匹配的节点，不再要求先在面板退役或等待转发终态。脚本停止整个服务及子进程后才清理，不把历史状态当作进程仍在运行的依据。
- 卸载自动保存 root 私有备份，保留既有备份及同机执行机；新增 `--check` 仅检查模式。错误身份、不安全文件归属、停止失败时不删除文件。
- 节点维护窗口增加直接获取本机卸载命令的入口，说明卸载与面板记录、预留端口的区别。

无需先升级面板或 Agent，即可下载本版本 `deploy/uninstall-agent.sh` 修复旧命令；要让后台显示新版命令，再升级面板。运行卸载会中断该节点全部现有连接，不会自动删除面板记录或释放预留端口。

## v2.1.0 · 节点与中转管理改进

- 修复空站恢复后首次注册被错误冻结、零下发记录的失败注册无法取消的问题；有业务或记录不完整的节点仍须核查，删除不等于远端停服。
- 安装前核对面板与令牌，安装后必须取得本次进程的真实同步结果。注册响应丢失可限时重试；旧缓存、进程 active 和文件回滚不再等同上线成功。
- 新增节点归档隐藏，保留远端状态、历史和端口占用；隧道可停止接纳新配置，与暂停已有转发分开。改名和排序不重启转发。
- 修复自备前置机就绪判断，改为后台任务；失败时标明是否需要核查客户 VPS，提供本次任务的定向清理。
- BBR 优化单独报告结果，失败尝试回退本次内核参数，不重载其他软件的网络配置。
- 加强重复主机、重叠地址端口池和待停止资源校验。历史租约到期不作为释放未知转发的依据，当前运行只使用 keep_last。
- 多出口诊断可选择实际出口，显示出口到客户 MSBOOST 的 TCP 建连时间，不表示游戏延迟或整条线路 RTT。

v2.0.1 的 systemd Caddy 安装可备份后升级；仍不支持旧 Docker Caddy 迁移。面板升级不自动升级独立 Agent：执行器需同步升级才能使用定向清理，节点请使用后台新版命令。Agent 进程升级可能中断连接，应安排维护时间。

## v2.0.1 · 系统 Caddy 全新部署版

这是破坏性部署更新，**只提供全新安装，不提供旧 Docker Caddy 迁移入口或旧数据迁移**。旧安装不能直接使用本版 upgrade；清理前自行另存需要的数据。

- 反向代理改为官方 Caddy systemd 服务。应用和 PostgreSQL 保持预构建 Docker Compose 部署，应用端口仅绑定宿主机回环地址。
- 按站点拆分配置。MSBOOST 只管理自己的站点片段；其他网站配置和共享证书不随升级、修复、卸载或清理被覆盖。
- 本站配置未变时不重载 Caddy；有变更时校验完整配置再重载，失败只回退本站文件。共享 Caddy 不随应用升级停止或重启。
- Cloudflare 来源检查限定在本站，直连请求不能用伪造转发头冒充客户端。
- 整站备份新增本站 Caddy 扩展，恢复保留其他网站。共享配置和共享证书不纳入 MSBOOST 数据包。恢复后仍须核对账务并重新开放营业。
- 保留在线备份、异地验证与回读、支付白名单、SMTP From 等现有业务功能。本版没有要求为 Caddy 调整重启独立节点。

控制面支持 Debian 12/13、amd64/arm64；官方发布需完成 CI 测试、预构建镜像与带校验清单的 Release 资产。安装和多站点配置示例见[部署说明](deployment.md)，备份范围见[整站备份](disaster-backup.md)。
