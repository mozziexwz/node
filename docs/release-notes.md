# MSBOOST v0.2.0 · 最终补充说明整改

按用户确认的最终版补充说明，完善免费工具、后台转发管理与安全恢复。面向 Debian 12（amd64 / arm64）安装调试；既有白橙 UI 保留。

- 中文站点 / Agent 安装阶段和错误指引，默认公告/教程、枫叶图标、免费工具在前的分组导航。
- SSH 提交时自动真实探测，首次信任并持久钉扎，后续主机密钥变化阻止执行；严格独立核对保留。首次信任不能代替 VPS 控制台独立验证。
- 免费部署及中转增加只读范围预览和二次确认清理，仅操作有所有权证明的本站组件；不删除备份、账户、依赖、共享缓存或第三方 GOST，不全局清空防火墙。
- 任务返回中文阶段、白名单诊断编号和下一步；健康状态中文化，DD 提交不冒充系统安装完成。自备中转支持配置备注。
- 执行机展示来源 IP、在线状态及最后心跳；管理员按邮箱、线路、状态查看和管理全部用户转发，撤销后按租约到期归档。
- 套餐授予速率、用户当前速率、每线路有效 min(用户,线路) 分开显示；改速率后全部规则各跳重新 ACK。仍为每规则限速，不是跨线路共享总带宽。
- 网页安全恢复白名单保留当前完整身份、财务及流量关联；新增完整离线灾难恢复工具，只导入全新 PostgreSQL 数据库 / SQLite 目录，旧库不覆盖。恢复后保持维护、撤销凭据、关闭支付并人工对账。
- 备份增加独立删除本机副本，保留远端与历史记录，保护最少有效副本及恢复前回滚副本。

## 已安装站点升级

先保管原 `/opt/msboost/.env` 和备份，不要卸载清空。网站升级不会自动更新独立 Agent：

```sh
msboost upgrade --version v0.2.0
```

升级先备份数据库；若原库已损坏，应按 [完整恢复指南](https://github.com/mozziexwz/node/blob/v0.2.0/docs/backup-recovery.md) 导入全新库，不要通过删除数据或跳过保护强行升级。

执行机和中转节点需在各自 VPS 按 [Agent 指南](https://github.com/mozziexwz/node/blob/v0.2.0/docs/agent-installation.md) 更新到同版本。执行机有任务时先等任务结束；重新注册会撤销旧令牌，节点更新可能重建连接。未更新的旧执行机不支持新清理和诊断契约。

新机器使用 [一键安装文档](https://github.com/mozziexwz/node/blob/v0.2.0/docs/deployment.md)。Docker Compose 优先 GHCR 预构建镜像，失败时使用同版本 Release 镜像归档，均校验来源与 SHA-256；不会静默改为本机构建。Release 包含两架构 Agent、两架构恢复工具及镜像归档。

继续保留 v0.1.2 的 Debian 12 版本变量污染修复与 `--recover-incomplete` 窄范围恢复路径，旧标签不覆盖。

自动化不等于真实 VPS 生产验收。没有操作客户 VPS、执行磁盘重装或真实付款；公网 SSH/DD、跨机转发与游戏、SMTP/商户回调、故障和对账演练仍需在可丢弃测试 VPS 完成。截图中的历史失败不能仅凭界面或 CPU 数值判定根因，新版诊断用于收集下一次实际执行的证据。
