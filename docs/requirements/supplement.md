# 补充说明修改清单

来源：用户提供的旧版 Word《补充说明.doc》，只读提取正文并人工核对全部 13 张嵌入截图。原始截图含浏览器与站点上下文，不随公开仓库发布。此处是产品要求与实现映射，不把附件中的示例数据视为实际部署参数。

| 要求 | 实现 |
|---|---|
| 管理员工具入口与侧栏一致 | 管理导航加入部署 MSBOOST、自备中转、DD |
| 用户信息及单位 | 验证状态、余额元、剩余天、总量/已用 GB、Mbps；五项数字排序；编辑保留未改变的原始值 |
| 执行机和节点一键部署 | 注册信息弹窗、一键下载校验后的 Agent、隐藏输入令牌；支持重新注册/重置，执行机有任务时拒绝重置 |
| 节点 / 隧道命名与配置 | 移除节点级强制前置；先节点后隧道；端口转发与隧道、入口、顺序多跳、出口池、方向倍率、TCP/TLS与地址偏好 |
| 增值用户隐藏入口 IP | 用户卡片和普通查询接口隐藏入口/中间路径，下载所需客户端配置仍包含连接信息 |
| 套餐体验限购 | 每套餐每用户购买次数，0 表示不限；后端交易校验，不只前端按钮限制 |
| 卡密删除和使用信息 | 已使用记录归档以保护账本；默认列表隐藏归档，可显式查看；显示状态、用户、时间 |
| 重复兑换及记录 | 新请求再次使用已用卡报错；同一请求的网络重试保持幂等；本人余额流水显示兑换卡密 |
| 订单用户 | 管理订单展示用户名（邮箱） |
| 文章排序和编辑器 | 标题前上/下箭头原子交换顺序；阅读标题大于分类且加粗；全屏覆盖完整编辑器，保留工具栏和保存按钮 |
| 邮箱购买门槛 | 注册与验证页独立开关，启用需要可用 SMTP，服务端实时检查 |
| 工单信息和排序 | 显示创建/最后回复时间、最后回复人角色；未关闭管理员最后回复→用户最后回复→新建→已关闭，同组最近活动优先 |

上述界面与自动化测试不能代替真实 VPS、邮件、商户和跨机网络验收。部署脚本不会替用户确认任何 DD 磁盘擦除操作。
