| 管理全部用户转发 | 邮箱、线路、状态筛选及详情/暂停/恢复/撤销；撤销后按租约到期归档；依赖冲突指向关联管理入口 |
| 明确并实际同步限速 | 套餐授予速率、用户当前速率、线路有效 min(用户,线路)；改速率使全部规则所有跳等待新 ACK，不将旧 ACK 显示为生效；不是账户跨线路共享总带宽 |
| 安全恢复与完整恢复分开 | 网页白名单安全恢复保留当前完整身份/商务/计量关联；离线完整恢复到全新数据库/目录，不读取或覆盖损坏旧库；恢复后维护、停用凭据并对账 |

清理保留备份、系统账户、软件依赖和共享二进制缓存，拒绝陌生布局及符号链接，不清理第三方 GOST 或重置全局防火墙。运行中的文件若在预览后变化，清理会拒绝，需检查后重做预览。完整恢复操作见 [恢复指南](../backup-recovery.md)。
